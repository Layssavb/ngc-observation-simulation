# Astronomical Observation Simulation

This repository contains codes, graphical analyses, and observational simulations developed for astronomical observation planning using real observational criteria adopted in professional observatories.

The project focuses on simulating the visibility and observational quality of galaxies from the NGC catalog, considering atmospheric, geometric, and temporal factors that directly affect astronomical observations.

---

# Project Goals

* Simulate astronomical observation sessions;
* Determine optimal observing windows;
* Compute object altitude and air mass;
* Analyze visibility conditions throughout the night;
* Compare observational conditions for different targets;
* Generate observational planning graphs.

---

# Studied Objects

The selected targets belong to the NGC catalog:

* NGC 10
* NGC 38
* NGC 47

---

# Observational Parameters

The simulations consider several important astronomical parameters, including:

* Right Ascension (RA)
* Declination (Dec)
* Object altitude
* Hour angle (HA)
* Local Sidereal Time (LST)
* Universal Time (UT)
* Air mass
* Moon illumination fraction
* Observatory latitude

---

# Telescopes and Observatories

The project uses observational parameters associated with:

* Gemini North Observatory (Mauna Kea)
* Gemini South Observatory (Cerro Tololo)

This allows comparisons between northern and southern hemisphere observing conditions.

---

# Generated Graphs

The repository includes plots such as:

* Altitude vs Local Time
* Altitude vs Sidereal Time
* Air Mass vs Time
* Visibility comparison between objects

These graphs help identify the best intervals for astronomical observations.

# Scientific Motivation

Astronomical observations require careful planning to maximize data quality. Factors such as atmospheric extinction, moonlight, object culmination, and air mass strongly influence observational efficiency.

This project reproduces essential steps commonly used in professional observational astronomy planning.
